# Live ERP24K - Selenium Automation Testing

## 📋 Project Overview

**Live ERP24K** is a comprehensive Selenium WebDriver automation testing framework designed for testing the 
**ERP24K Retail Store Management System** (https://www.erp24k.com/). 

This project automates critical business workflows including:
- ✅ User Authentication & Login
- ✅ Inventory Management
- ✅ Single & Multiple Barcode Generation (Weight-based)
- ✅ Product Masters Management
- ✅ Purity Management
- ✅ Pricing Configuration
- ✅ Dashboard Operations
